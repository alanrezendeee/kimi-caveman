# Caveman Mode Reference

## Triggers

| Activate | Deactivate |
|----------|------------|
| "caveman mode" | "stop caveman" |
| "modo caveman" | "normal mode" |
| "talk like caveman" | "desativar caveman" |
| "less tokens" | "verbose mode" |
| "compact mode" | "full sentences" |
| "ultra terse" | — |

## Levels

### 🪶 Lite
- Drop filler only
- Grammar intact
- Professional

### 🪨 Full (default)
- Drop articles
- Sentence fragments
- Imperative verbs

### 🔥 Ultra
- Maximum compression
- Telegraphic
- Abbreviate

### 📜 文言文
- Classical Chinese
- Maximum terseness

## Commands

| Command | What |
|---------|------|
| `caveman-compress <file>` | Rewrite markdown to caveman-speak |
| `caveman-commit` | Terse commit message (≤50 chars) |
| `caveman-review` | One-line code review |
| `caveman-help` | Show this card |

## Rules

1. Never change code blocks
2. Never lose technical info
3. Never be rude
4. Keep structure (lists, tables)
5. Emoji sparingly
